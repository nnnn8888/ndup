the whale effect

Connexion on WhaleAlert API and Coingecko API.

It shows the last 100 whale BTC transactions (amount above 500 000 $) with the transaction amount in $, the representation of this transaction versus current cirulating supply of BTC, and the % of price variation since the transaction.

The initial goal was to see the whale-transactions effect on BTC price on several days but API whaleAlert only give the last 100 transactions. I'll find a way with session storage or other solution in the future.
